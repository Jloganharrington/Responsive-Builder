## TECHNICAL REQUIREMENTS

- Single HTML file — embedded CSS and JS only
- Tailwind CDN is acceptable but not required
- Mobile-first, fully responsive
- No backend, no external API dependencies
- All color swatches rendered via CSS background-color only — 
  no image dependencies for swatches
- Smooth scroll to color section when a product card is selected
- Product cards visually update on selection: #6DB33F border, 
  green checkmark top-right corner
- HOA Match star badge: #E8A020 filled circle, white ★ symbol, 
  positioned absolute top-right corner of swatch tile
- All plygem.com product links open in new tab (target="_blank")
- Color grid shows ONLY colors available for the currently 
  selected product — grid re-renders on product change
- On load: no product selected, no color selected, summary 
  card shows "—" for unselected fields
- On mobile: product cards stack vertically, color grid is 4 columns
- On desktop: product cards are 3 columns side-by-side, 
  color grid is 6 columns
